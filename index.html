去钓鱼

低多边形 3D 海岛钓鱼休闲游戏

怎么玩

  1. 在海岛上捡海产品（贝壳、海螺），卖掉换钱
  2. 找商店老板买钓竿和鱼饵
  3. 选中钓竿，按住左键蓄力，松开抛竿
  4. 咬钩后按左键提竿，按住左键收线，张力条变红要松手
  5. 烤鱼能卖更多钱，但要注意火候

操作

W A S D 移动
Shift 冲刺
鼠标 视角
滚轮 / 1~9 切换手持物品
左键 抛竿 / 收线 / 进食
右键 快速收竿
E 交互
X 放下物品
B 切换鱼饵
F 检视物品
V 统计面板
C 切换视角
Esc 设置 / 暂停

点击后鼠标会被锁定。按 Esc 解锁并暂停。
